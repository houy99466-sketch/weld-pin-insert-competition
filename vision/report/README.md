## 四条技术路线（对应报告章节）

| 路线 | 关键素材 | 可用的结论 |
|---|---|---|
| RGB 参考纹理旋转 | 01 误差分布、02/03 接受与拒识、04/05 真实视频 | 同源合成测试已接受 MAE 0.0619°；实拍迁移两张均被拒识 |
| 实例分割 + 二维方向 | 07 训练曲线、08/09 伪标签与预测、10 失败案例、11 旋转等变 | 掩膜 mAP50 0.515 → 0.695（对自动标签的一致性）；等变误差 ~0.29° |

| 混合三类数据 | 17 类别定义、18 标注预览、19 坐标复核 | 3,209 帧（训练 2,174 / 验证 1,035）；新旧 CT 含义不同 |

## 引用时的措辞红线

素材作者在 [项目报告素材.md](项目报告素材.md) 第 8 节列了 5 条，照抄即可。最容易被念错的三条：

1. **0.0619° 不是实物测角精度**，是"同来源合成图已接受样本 MAE"。
2. **mAP 是对自动标签的一致性**，不是人工验收准确率。
3. **IoU 0.918 是同帧轮廓一致性**，不是位姿准确率。

另外：本仓库的视觉侧目前**止于感知原型**——没有手眼标定、没有机器人坐标变换、没有抓取闭环证据。
报告里写"视觉感知与位姿估计原型"，别写"已完成机器人自动抓取闭环"。

## 与仓库其他目录的关系

```
├─ vision/            视觉代码与当前数据集（本目录的上一级）
│  ├─ 视觉方案.md      实际使用的视觉方案
│  └─ report/         ← 本目录：报告素材，只读归档，不再改动
└─ real_robot/        机械臂侧（调试台 / 示教）
```

`vision/` 里现有的 `extract_frames.py` / `train.py` / `predict.py` 与 `dataset/data.yaml`（6 类 OBB）
是早期备选的轻量方案（未投入使用）；本目录的素材来自实际跑的视觉实验链路（分割 + RGB-D + 6D 位姿），
两者编号与类别定义不同，**不要把 report 里的指标套到 OBB 模型上**。

## 增加新素材

1. 图放 `images/`，编号续排（`20_xxx.png`），文件名用英文小写下划线；
2. 同步更新 `图片素材与图注.md` 和 `素材清单.json`；
3. 视频放 `videos/`，同样续号；
4. 涉及的指标必须同步一份到 `evidence/`，否则报告里的数字没有出处。
